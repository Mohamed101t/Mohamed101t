## 🎓 Graduation Project — SyncField

### SyncField: Offline-First Mobile Data Collection & Synchronization System

**SyncField** is my graduation project, designed for collecting and managing structured field data in environments with weak, intermittent, or unavailable Internet connectivity.

The system allows users to continue working offline and safely synchronize their data with a central server when connectivity becomes available.

### Key Features
- Offline-first data collection
- Local data storage using SQLite
- Manual and reliable synchronization
- Duplicate prevention using stable identifiers
- Role-based access control
- Supervisor and user permissions
- Record update, delete, and restore workflows
- Conflict detection and resolution
- Arabic and English support
- Centralized reporting and data management

### Technologies

`Flutter` `Dart` `SQLite` `Node.js` `Express.js` `PostgreSQL` `REST API`
